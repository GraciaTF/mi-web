Uno de los proyectos que realicé durante mi formación en Lenguaje de Marcas, donde trabajé con HTML y CSS para crear y estructurar una página web. Posteriormente le añadí algunas interacciones usando JavaScript.

Proyecto académico · Sistema de bibliotecas en Java

Proyecto realizado durante mi formación autodidacta en Java mediante el MOOC de Java de la Universidad de Helsinki.

En este proyecto trabajé conceptos de programación orientada a objetos creando diferentes tipos de bibliotecas y definiendo comportamientos distintos para cada una. Quise hacerlo como actividad extra complementaria a las propuestas por el propio MOOC para poder consolidar los aprendizajes y coger un poco de experiencia práctica.

El programa incluye una biblioteca con un límite máximo de páginas, una biblioteca que solo permite almacenar un libro y una biblioteca sin límite específico. También trabajé la comparación de objetos mediante equals() y hashCode().
